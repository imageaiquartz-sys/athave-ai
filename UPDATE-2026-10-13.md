# Athave AI — Gallery, Login and Upload UI refinements

- The first image in the “Every detail, elevated.” showcase is the user-provided transparent Athave AI sneaker pair, optimized as WebP. The homepage hero is unchanged.
- Admin > Website images > Showcase gallery remains editable. Resetting gallery slot 1 returns to the new sneaker picture. If a custom slot 1 image is already saved in the deployed database, it still takes precedence until the admin resets that slot.
- The phone login entry now has a single outer border, including while focused; the separate nested input outline is disabled. OTP/login logic is unchanged.
- Account profile and admin customer cards use a reusable neutral SVG silhouette rather than initials.
- Monthly plan promo headline and pricing figures use Manrope sans-serif with tuned font weight and spacing. Prices, plan logic and payment integration were not changed.
- Upload no longer asks customer/shop name or contact and no longer calls the customer-update endpoint. It uses the existing OTP-linked account details; plan and upload API remain untouched.
- Updated service-worker cache name and added new assets so existing PWA installs can refresh after deployment.
