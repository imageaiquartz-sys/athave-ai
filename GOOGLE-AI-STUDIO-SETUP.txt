ATHAVE AI — CONNECT GEMINI IMAGE AI

1. Log into https://aistudio.google.com/api-keys with the business Google account used for paid Gemini API calls.
2. Copy the API key for the billing-enabled Gemini project. Do not paste the key into GitHub or frontend HTML/JS.
3. In Cloudflare dashboard → Workers & Pages → athave-ai → Settings → Variables and Secrets → Production, add:

   GEMINI_API_KEY        Secret  <your real API key>
   GEMINI_IMAGE_MODEL    Text    gemini-3.1-flash-lite-image
   ANALYSIS_MODEL       Text    gemini-3.5-flash-lite
   GENERATION_ENABLED   Text    false
   AI_MONTHLY_CALL_CAP  Text    20
   MAX_GENERATIONS_PER_DAY Text 5

4. Save variables and redeploy latest successful Production deployment.
5. Log into https://athave-ai.pages.dev/ with OTP, then visit https://athave-ai.pages.dev/api/ai/check in the same browser.
   Expect configured:true and accessible:true (model/key metadata confirmed, not an actual image test).
6. Before enabling image generation, confirm Supabase private bucket athave-results, customers, wallets, jobs and payment system are working.
7. Set GENERATION_ENABLED = true, redeploy, and try one image. Each requested output consumes one credit; clothing front + back is usually TWO outputs.
8. Once successful, increase AI_MONTHLY_CALL_CAP and MAX_GENERATIONS_PER_DAY carefully according to your budget.

Cost: See https://ai.google.dev/gemini-api/docs/pricing for current image output/input prices. WebP compression is performed at download in the browser, using a 1024x1024 pure-white canvas. AI-inferred backs must be checked for accuracy.
